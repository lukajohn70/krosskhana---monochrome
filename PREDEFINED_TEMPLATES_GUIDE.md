# Predefined Email Templates - Krosskhana Admin Dashboard

## 🎉 **Overview**

Your admin dashboard now includes **8 professional predefined email templates** that you can easily select and customize for various types of campaigns. These templates are designed to match your website's professional appearance and provide ready-to-use content for common email marketing scenarios.

## 📧 **Available Templates**

### **1. Newsletter Update**
- **Use for**: Regular newsletter updates with news, events, and community highlights
- **Subject**: "Krosskhana Newsletter - Latest Updates"
- **Content**: Includes sections for motor sport events, entertainment & culture, and community highlights
- **Perfect for**: Monthly newsletters, weekly updates, community news

- **Use for**: Announcing new events with details, registration info, and what to expect

## 🚀 **How to Use Templates**

### **Step 1: Access Templates**
1. Go to **Campaign Management** in your admin dashboard
2. Click **"Create Campaign"**
3. In the campaign form, click **"Choose Template"** button

### **Step 2: Select Template**
1. Browse through the available templates
2. Each template shows:
   - Template name
   - Subject line
   - Description of use case
3. Click on the template you want to use

### **Step 3: Customize Content**
1. The template will automatically load into your campaign form
2. **Subject line** will be pre-filled
3. **Content** will be loaded into the editor
4. Customize the content as needed:
   - Replace placeholders with actual information
   - Modify text to match your specific campaign
   - Add or remove sections as needed

### **Step 4: Send Campaign**
1. Review your customized content
2. Select your target audience
3. Choose send options (immediate or scheduled)
4. Click **"Create Campaign"** to send

## 🔧 **Template Placeholders**

### **Event-Related Placeholders**
- `[EVENT_NAME]` - Name of the event
- `[EVENT_DATE]` - Date of the event
- `[EVENT_TIME]` - Time of the event
- `[EVENT_LOCATION]` - Location of the event

### **Customer-Related Placeholders**
- `[CUSTOMER_NAME]` - Customer's name
- `[TICKET_NUMBER]` - Ticket or reference number

### **Promotional Placeholders**
- `[OFFER_DETAILS]` - Details of the promotional offer
- `[EXPIRY_DATE]` - Offer expiry date
- `[PROMO_CODE]` - Promotional code

### **Product-Related Placeholders**
- `[PRODUCT_NAME]` - Name of the product or service
- `[PRODUCT_DESCRIPTION]` - Description of the product or service
- `[LAUNCH_DATE]` - Product launch date

## 🔄 **Template Management**

### **Current Templates**
All templates are stored in `includes/email-templates.php` and can be easily modified or extended.

### **Adding New Templates**
To add new templates:
1. Edit `includes/email-templates.php`
2. Add new template to `getPredefinedCampaignTemplates()` function
3. Add description to `getTemplateDescription()` function
4. Test the new template

### **Customizing Templates**
- **Colors**: Modify colors in the template CSS
- **Layout**: Adjust layout and spacing
- **Content**: Update default content and placeholders
- **Branding**: Update logo and brand elements
