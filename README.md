# Krosskhana - Automotive Lifestyle Event Website

## 🏁 About

Krosskhana is an automotive lifestyle company that seamlessly blends motor sport with diverse forms of entertainment, including music, fashion, and cultural exhibitions. We are revolution on wheels, transcending traditional motor sport by fusing high-octane racing thrills with the pulse of music, fashion, and art.

## 🚗 Features

- **Modern Responsive Design**: Built with Tailwind CSS for a beautiful, mobile-first experience
- **Interactive Elements**: Smooth animations and transitions throughout the site
- **Video Backgrounds**: Dynamic video content showcasing automotive culture
- **Event Management**: Past and upcoming events with detailed information
- **Team Showcase**: Meet the passionate team behind Krosskhana
- **Sponsorship Opportunities**: Detailed sponsorship packages and partnership options
- **Contact Forms**: Multiple contact options for different types of inquiries

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Styling**: Tailwind CSS
- **Icons**: Font Awesome
- **Fonts**: Google Fonts (Poppins)
- **Backend**: PHP
- **Server**: MAMP/XAMPP compatible

## 🚀 Getting Started

### Prerequisites

- Web server (Apache/Nginx)
- PHP 7.4 or higher
- Modern web browser

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/krosskhana.git
   ```

2. Navigate to the project directory:
   ```bash
   cd krosskhana
   ```

3. Set up your web server to point to the project directory

4. Open the website in your browser:
   ```
   http://localhost/krosskhana
   ```
